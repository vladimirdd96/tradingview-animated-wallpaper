# TradingView Desktop animated wallpaper demonstration

The creator requested publication of this short recording of their existing TradingView Desktop session. Captured on 2026-10-24 from the actual running macOS app, without launching another instance or changing the wallpaper settings.

- 10 seconds, silent, 1280 × 620 H.264 MP4 in the v1.1.1 release.
- This directory contains an 800-pixel looping GIF preview at 8 fps.
- Cropped to chart content, excluding account information, sidebar, and trading controls. No color or brightness enhancement was applied.
- Shows a user-selected Naruto animated wallpaper behind candlesticks. The original wallpaper file is not distributed, and the installation ZIPs do not contain this demo.
